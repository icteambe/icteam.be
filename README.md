# icteam.be

Static site for https://icteam.be with company details and Peppol information.

## Local development
Just open `index.html` in a browser. No build step required.

## Publishing on GitHub Pages
1. Create a new repository named `icteam.be` and push this content.
2. In repository settings, enable GitHub Pages from the `main` branch (root folder).
3. Keep the `CNAME` file so the custom domain stays mapped to `icteam.be`.

That is all—Pages will publish automatically after the first push.
